# Botão Champions

Fala meu parceiro, tamo junto? Negócio é o seguinte: eu quero que você crie o famoso aquele jogo de futebol de botão, tá ligado? E eu quero que você forme primeiro pra jogar um amistoso e o torneio. O torneio é como se fosse um campeonatinho mesmo, uma, uma Champions League, uma Libertadores. Primeira fase de grupo, depois a fase de mata-mata, entendeu? Cê cria tudo aleatoriamente com, com os time brasileiro e tal, entendeu? Pra selecionar tudo e pra jogar o futebol de botão dentro dum torneio, onde primeira fase de grupo, depois é eliminatória de, de futebol de botão, com três níveis de dificuldade e com-- e, e tipo, em forma de fase, entendeu? Tipo, quando o cara for campeão uma vez, ele ganha um troféu, daí depois ele ganha outro troféu. Se ele for campeão três vezes, ele desbloqueia a próxima, entendeu? Cria alguma lógica assim de jogo, mas cria um top bem massa, bem profissional e que seja compatível tanto com computador, tanto com, ééé, o celular. E também ele vai ser acolo-acoplado dentro de outro projeto, entendeu? Então ele é um, um-- ele é um módulo dentro de um módulo principal
